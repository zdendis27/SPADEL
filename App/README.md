# App

Sem patří Xcode projekt SPADEL (vytvoří se v týdnu T1).

Doporučené nastavení při zakládání v Xcode:
- šablona **watchOS → App** se zaškrtnutým „Watch App with New Companion iOS App“
- Product Name: `SPADEL`, Interface: SwiftUI, Language: Swift
- zaškrtnout **Include Tests**
- uložit do této složky `App/` (bez vytváření nového git repozitáře, ten už existuje)
